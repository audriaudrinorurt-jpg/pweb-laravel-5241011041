## ⚙️ Cara Menjalankan Project

1. Clone repository:
   git clone https://github.com/audriaudrinorurt-jpg/pweb-laravel-5241011041.git

2. Masuk ke folder project:
   cd pweb-laravel-5241011041

3. Install dependency:
   composer install

4. Copy file environment:
   copy .env.example .env

5. Generate key:
   php artisan key:generate

6. Jalankan server:
   php artisan serve

7. Buka di browser:
   http://127.0.0.1:8000
